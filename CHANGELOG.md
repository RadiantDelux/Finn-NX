## 0.1.11

Initial public release.

- Run Jumping Finn Turbo Android 1.1.6 through the android32 Unity/Mono host.
- Support OpenGL ES graphics, FMOD audio, touchscreen input and docked controls.
- Validate any APK filename by its full SHA-256.
- Install and launch a HOME forwarder from the NRO, including Album startup.
- Include run restart, the pink pointer and the Y kick / X recovery mapping.
- Display RadiantDelux as author in the NRO and generated forwarder.
- Ship an APK-free SD package with instructions and third-party notices.
