FINN NX — Jumping Finn Turbo for Nintendo Switch homebrew
https://github.com/RadiantDelux/Finn-NX

ENGLISH

1. Copy switch/finn_nx/finn_nx.nro to the same path on your SD card.
2. Put your own Android 1.1.6 APK in /switch/finn_nx/ (any .apk filename).
3. Open the NRO from Album/hbmenu. It reuses an installed Finn forwarder or
   creates its HOME icon, confirms installation and requests the game launch.
4. Let the first launch extract the native libraries. Later, use the HOME icon.

Requires Atmosphere configured for homebrew forwarders. If automatic setup
fails, use Install Forwarder in sphaira and open the resulting HOME icon.

APK: Jumping Finn Turbo Android 1.1.6, com.turner.jft, armeabi-v7a.
Size: 50,439,654 bytes. Required SHA-256:
7b3c4d0058c8f613b0a696fbbdd96b4fd0162e75d3ee85da11d9f38cf768d040
The game is not included in this public download.

Y: Jake kick. X: recovery. B: launch gauge (two presses), then tap actions;
hold B during flight to repeat. L/ZL: left penguins. R/ZR: right penguins.
Minus: restart this run, keeping saved progress. Plus: pause menu.
Left stick: pointer. A: click/drag. Right-stick click: Back. L+R+Plus: exit.
The touchscreen also works. Other buttons hide the pointer; A keeps it visible.

Update by replacing the NRO. Keep your APK and /switch/finn_nx/data/ saves.
For setup failures, retain forwarder-install.log. For game failures, retain
debug.log and crash.log, if generated. Include port and Atmosphere versions.

ESPANOL

1. Copia switch/finn_nx/finn_nx.nro en esa misma ruta de tu SD.
2. Pon tu APK Android 1.1.6 en /switch/finn_nx/; el nombre puede ser cualquiera.
3. Abre el NRO desde Album/hbmenu. Reutiliza el forwarder existente o crea
   su icono en HOME, confirma la instalacion y solicita iniciar el juego.
4. Deja terminar la extraccion inicial. Despues puedes usar el icono de HOME.

Requiere Atmosphere configurado para forwarders homebrew. Como alternativa,
usa Install Forwarder en sphaira y abre el nuevo icono desde HOME.
El APK exacto y su SHA-256 estan indicados arriba. Este paquete publico no
incluye el juego. El NRO lanza una aplicacion ARM32; Unity no corre en el applet.

Y: patada de Jake. X: recovery. B: medidor inicial (dos pulsaciones) y toques;
mantener B durante el vuelo repite. L/ZL: pinguinos izquierdos. R/ZR: derechos.
Menos: reinicia la run, sin borrar la partida. Mas: menu de pausa.
Stick izquierdo: cursor. A: pulsar/arrastrar. Clic stick derecho: atras.
L+R+Mas: salir. Tambien funciona la pantalla tactil.

Para actualizar sustituye el NRO y conserva el APK y data/. Si falla el inicio,
conserva forwarder-install.log, debug.log y crash.log (si se genera).
